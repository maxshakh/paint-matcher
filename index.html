📚 Источники данных

Каждая линейка приведена к достоверным данным: пары «номер↔название» — из официальных каталогов производителей, HEX — из измеренных свотчей сообщества (краска нанесена, сфотографирована, усреднена) либо из привязок к промышленным стандартам RAL/RLM/FS. Металлики заданы средними тонами по типу металла (условно). Ниже — все использованные источники.

🎨 Измеренные HEX (свотчи)

  • Citadel (Base + Layer) — Tale of Painters swatches, датасет SimoGecko/CitadelColours (краска нанесена, сфотографирована, усреднена).
  • Vallejo Model Color — Basecoat Lab · Model Color (measured swatches).
  • Vallejo Game Color — Basecoat Lab · Game Color (значения зеркалятся на Game Air).
  • AK Interactive 3rd Generation — Basecoat Lab · 3rd Gen Acrylic.
  • The Army Painter — Warpaints Fanatic — Basecoat Lab · Warpaints Fanatic.
  • Scale75 — Scalecolor — Basecoat Lab · Scalecolor.
  • Green Stuff World — Maxx Formula — Basecoat Lab · Maxx Formula.

🗂️ Каталожные HEX (справочные)

  • Vallejo Model Air — Paint Vault · Model Air (полный список 251 цвет, номера и названия). ⚠️ Измеренных свотчей Model Air нет ни в Basecoat Lab, ни в других открытых датасетах. Поэтому для военных тонов HEX взят из привязок RAL/RLM/FS (авторитетно), для части базовых цветов (Fire Red, Ferrari Red, Orange, Steel Blue и т.п.) — каталожно-приблизительный (по печатной карте/Paint Vault). Эти значения помечены как ориентировочные — проверяйте сухим мазком.
  • Общий справочник — paint-vault.com (кросс-бренд эквиваленты и палитры).

📖 Официальные каталоги (номера и названия)

  • Vallejo Model Color / Model Air — офиц. чарт CC329 (Model Color, PDF) и таблица эквивалентов RAL/RLM/FS/ANA (CC340).
  • Vallejo — общий сайт acrylicosvallejo.com.
  • AK Interactive 3rd Gen — офиц. цветовая карта и таблица эквивалентности (коды AK11001–AK11236).
  • The Army Painter — thearmypainter.com.
  • Games Workshop / Citadel — games-workshop.com.
  • Scale75 — scale75.com · Green Stuff World — greenstuffworld.com.

🏭 Промышленные стандарты

  • RAL Classic — стандартные sRGB-эквиваленты палитры RAL (полный набор, включая RAL 7028 Dunkelgelb).
  • FS 595 — Federal Standard 595 (авиационные/военные цвета).
  • RLM — референсные значения Luftwaffe RLM (для военных тонов Model Air / AK).
⚠️ Измеренные свотчи — приближение к реальной банке, но существенно точнее печатных каталогов и генеративных оценок. Металлики одним HEX точно не передаются (блеск/отражения) — используйте средние тоны как ориентир и проверяйте сухим мазком.
Работает офлайн. Линейки: Vallejo (Model Color / Model Air / Game Color / Game Air), AK 3rd Gen, Citadel, Army Painter, Scale75, GSW, плюс промышленные стандарты RAL Classic (полный, включая RAL 7028 Dunkelgelb) и FS 595. 💡 Клик по образцу — свотч 100×100 с подписью «производитель — название — номер»; клик по ΔE — разбор dL/da/db с легендой CIELAB и подсказкой по смешиванию. Ползунок «Максимальный ΔE» скрывает далёкие совпадения; колонки в таблице соответствий можно перетаскивать. 🗄️ Вкладка «Мой склад» хранит имеющиеся у вас краски (офлайн, в браузере). HEX — из измеренных свотчей сообщества и стандартов RAL/RLM/FS (см. вкладку «Источники данных»); металлики — усреднённые тона. Финальная проверка — сухим мазком.
